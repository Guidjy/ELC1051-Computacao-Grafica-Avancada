# Tohno Mansion — PS2-style fighting game stage

Low-poly (~28.6k triangles) 3D recreation of the Tohno Mansion grand hall: twin curved staircases, bowed balcony with an arch into the back room, timber-framed upper galleries, elliptical night-sky dome and crystal chandelier.

## Install in Unity

1. Copy the `TohnoMansion` folder into your project's `Assets/Stages/` (keep that path — the importer keys off it).
2. Wait for the import. If materials look pink/grey, run **Tools → PS2 Stage → Reimport Tohno Mansion** (the shaders need to compile before the model is processed the first time).
3. Run **Tools → PS2 Stage → Add Tohno Mansion To Scene**. This places the stage, sets up the main camera with `FightingStageCamera`, and adds dark-blue distance fog.
4. Drag your two fighters into the camera's `Player 1` / `Player 2` slots.

## How it's lit

Lighting is **baked into vertex colours** the way PS2 games did it (warm chandelier pool, cool moonlight from the dome, back-room lamp, gallery sconces, depth haze and edge falloff). No realtime lights are needed — the environment uses:

- `PS2Stage/VertexLit` — texture × vertex colour, unlit, with optional colour banding for that PS2 output look. Has a `Brightness` slider if you need to match your characters.
- `PS2Stage/Glow` — additive sprites for the chandelier bulbs, halo, floor light pool and sconces, with a subtle candle flicker.

Both shaders work in the Built-in pipeline and URP. Because the stage is unlit, light your characters separately (e.g. one warm directional light on a "Characters" layer culled from nothing else). Bloom on the glow sprites looks great if your pipeline has post-processing.

## Stage markers (empties in the FBX)

| Marker | Purpose |
|---|---|
| `MK_CameraStart` | Default camera position |
| `MK_CameraPanLeft` / `MK_CameraPanRight` | Ends of the horizontal camera rail (±4.5 m) |
| `MK_FightLine_Left` / `MK_FightLine_Right` | Stage walls on the fight line (±9 m) — clamp fighters here |
| `MK_P1_Spawn` / `MK_P2_Spawn` | Round-start positions |

`FightingStageCamera` exposes these as `FightLineLeft`, `FightLineRight`, `P1Spawn`, `P2Spawn`. The fight line sits on the floor (height 0), 11 m in front of the camera. Camera: 46° vertical FOV, tilted up 7.5°.

## Editing in Blender

`Blender/TohnoMansion.blend` opens with the fight camera set up; viewport *Rendered* mode shows exactly the game look (emission-only materials). The whole scene is generated by `Blender/build_tohno_mansion.py` (+ `textures.py`). Tweak the constants or the `LIGHTS` list at the top and re-run:

```
blender -b -P build_tohno_mansion.py            # rebuild .blend + FBX
blender -b -P build_tohno_mansion.py -- --render  # also render the three camera previews
```

Note that the stage is enclosed for the camera's travel range only — the front side of the room is open.
